Provably fair

Every crash point is decided before the round from a secret random seed. Before betting opens we publish the seed's SHA-256 hash. After the crash we reveal the seed, so anyone can check that it matches the hash and produces exactly the crash point that happened. Changing the result afterwards would break one of the two checks.

How it works

  1. hash = SHA-256(seed) is shown before the round.
  2. h = first 52 bits of HMAC-SHA256(seed, "VELTRIX"), r = h / 2^52.
  3. crash = max(1.00, floor(100 · 0.97 / (1 − r)) / 100)
  4. The 3% house edge means every strategy returns 97% on average.
